# 见习音效师工程（Claude Code 版）

Claude Code 版「agent 工程文件夹」。在本文件夹启动 Claude Code（`claude` 交互式，或 `claude -p` 无头模式）即自动生效：CLAUDE.md、三个 subagent、三个 slash 命令、三个 skill 全部就位。

> 前身：ZCode 版 `..\见习音效师工程\`（历史档案，冻结不再推进）。方法论权威：`Desktop\音效工作流交接包_20260922\`。

## 使用

1. 终端 cd 到本目录，运行 `claude`（新会话自动加载全部架构）。
2. **新用户（或换机/配置缺失）第一步先跑 `/开始`**：检测音源库（NAS `\\192.168.9.251\音效2\资源库` 或本地 `D:\音效文件`）→ 自选资产表 db 来源 → 写机器级配置 `~/.claude/foley_machine_config.json`。已配置过的机器跳过。
3. 原始视频放进 `sources/`，输入 `/分析 sources/xxx.mp4`，视频分析师产出逐秒报告到**本次任务的工作目录**（制作人指定，如 `D:\reaper工程\<工程名>\reports\`）。
4. 输入 `/贴轨 <报告完整路径>` 下单；完成后 `/质检` 验收。
5. 也可以直接对话点名：「让音效总监接这一集」「让见习音效师贴第三段」。

## 程序化驱动（无头模式）

```
claude -p "执行 /贴轨 D:\reaper工程\<工程名>\reports\ep03.md" --output-format stream-json
```

适合批处理多集任务或接入外部调度脚本。⚠️ 并发限流铁律：子 agent 并发派活 ≤2 路，默认 1 路串行（20260914 事故）。

- 本工程整个目录复制，即可作为新剧集/新项目的模板；用 git 管理（`git init` 后提交即可）。
- 方法论文档（00~12 号）在交接包内，不在工程里复制——保持单一权威来源。
