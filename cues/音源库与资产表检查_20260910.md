### ⚠️ 使用注意点

1. **cues 表数据不可依赖**：856 行 `len_sec` 全部为 NULL，`label` 为 `Tempo: 120.0` 之类解析残留。即「同源异段取窗」不能查表现状数据——`start_offset` 一律由 place 脚本 CUES 表手工设计（历史实战即此做法，见交接包 05 号文档 cue 字段 6）。后续若要用 DB 取窗，先人工验证该表质量。
2. **search_assets.py 命令行直跑会报错**：脚本硬编码 `BASE_DIR/index/asset_library.db`（原机目录布局），本包 DB 在 `scripts/pipeline/` 下，CLI 直跑报 `unable to open database file`。正确用法：
   ```python
   import sys
   sys.path.insert(0, r"C:\Users\Administrator\Desktop\音效工作流交接包_20260907\scripts\pipeline")
   from search_assets import search
   hits = search(r"...\asset_library.db", "关键词", top_k=5)
   ```
   或直接用交接包 04 号文档的 `q()` / SQL 模式。
