# 坑与 FAQ 速查（foley 工作流域）

> 出问题先查这张表。**权威边界**：本册只管 foley 工作流域（报告核验/选材/音源/贴轨口径）；
> REAPER 连接/API/渲染/保存/rpp 编辑层 → `reaper-remote-ops` §7 坑速查表 `[R-xx]`；选材规则本体 → `references/retrieval.md`。

> **维护规则（改本册前必读）**：
> 1. 条目编号 W-xx（工作流）/ X-xx（音源检索）递增、**不复用**（删条目留空号），跨文件引用写作 `[W-xx]`；
> 2. 条目=「症状 → if/动作」，分支指令式、判据量化，**禁案情叙述与日期戳**——历史归交接包 `12_变更记录.md`；
> 3. 与现行条款冲突的旧条目立即废除（如 D_VOL 补偿 vs 音量不动条款）；
> 4. 改后三副本同步（交接包 skill快照 → 工程内 .claude/skills → 全局 ~/.claude/skills）+ sha1 校验。

## 工作流类

| 编号 | 现象 | 动作 |
|------|------|------|
| W-01 | 报告里的动作在视频里不存在 | 假动作（报告幻觉）：帧证据核验一票否决，剔掉不贴；疑似假动作上报制作人，**任何人禁改判** |
| W-02 | 报告时间戳与画面对不上 | 以抽帧实际内容为准修正 |
| W-03 | 同一音效一集反复出现 | 违反选材规则 → retrieval.md（同源 ≤2 + 异窗轮换） |
| W-04 | 新集不知道 Region 起点 | `extract_regions.py` 离线解析 RPP 或实测显式传入，**禁估算**；跨派单数值引用落盘文件，禁手抄 |
| W-05 | 长条音效拼接露馅 | silencedetect 边界 ≥5 = oneshot 序列禁止硬拼；找长连续源取窗 |
| W-06 | 同源多处使用听感重复 | 必须取不同时间窗/切段，或换近义音源 |
| W-07 | audit_offsets.py 参数口径 | `--ep` 未命中 Region 且未传 `--base` → 报错退出（禁静默退化为全时间线审计）；`--base` 可单独传定审计起点，配合 `--ep` 时作未命中兜底 |
| W-08 | place 防重判读漏判重复 | 条目名是「label ｜ 源文件名」合并写法：防重比对先按「｜」拆出 label 段再比对（place 模板已内置） |
| W-09 | 事件音在剪辑点戛然而止 | 切镜头 ≠ 切声音：延长漫过切点 + `D_FADEOUTLEN` 淡出 |

## 音源 / 检索类

| 编号 | 现象 | 动作 |
|------|------|------|
| X-01 | 中文素材检索假阴性 | FTS5 默认分词不切中文连续串：desc 必须空格分隔关键词，新包入库逐条写 desc（见 retrieval.md） |
| X-02 | 素材贴上≈无声（保守电平源如 CK 层） | volumedetect 查源电平；**D_VOL 不动**（音画条款，禁调量补偿）：电平过低 → 换源或报存疑清单 |
| X-03 | item 有位置无波形/无声（空块） | take source 赋值丢失：回读验证 + 重贴；防重判定必须验 source 不验位置 |
| X-04 | 贴完看不到波形 | ①volumedetect 查源电平 → ②peaks 缓存（place 模板已内置 `build_peaks()` 自动建峰，手动「峰值→构建峰值」仅兜底）→ ③查轨/条目 mute |
| X-05 | subprocess 读 ffmpeg 输出抛 UnicodeDecodeError / 判读误判 | ffmpeg stderr 含非 UTF-8 字节：`subprocess.run(..., text=True, errors="replace")` 容错后再解析 |
| X-06 | DB 报 `no such module: fts5` | Python 换官方编译版（自带 FTS5） |
