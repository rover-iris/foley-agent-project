执行首次引导（$ARGUMENTS 可选：`重配` 重新配置 / `查看` 仅展示现状）：

1. **读现有配置**：`~/.claude/foley_machine_config.json` 已存在 → 展示并询问是否重配（参数为 `重配` 时直接进入配置流程；`查看` 时仅展示并结束）。
2. **检测音源库模式**（python 只读探测；**必须写临时脚本文件执行，禁止 bash 内联传 UNC 路径**——实测内联会静默失败）：
   - `\\192.168.9.251\音效2\资源库` 可达 → 模式 `nas`
   - `D:\音效文件` 存在 → 模式 `local`
   - 两者都在 → 询问用户选哪个；都没有 → 停止，引导联系制作人，禁止猜测其他路径
3. **选资产表 db**（用 AskUserQuestion 给可选项）：
   - `nas` 模式默认：`\\192.168.9.251\音效2\资源库\_索引\asset_library_nas.db`（NAS 路径版，60,871 条）
   - 工程内副本：`<工程根>\assets\asset_library_nas.db`
   - 本机特供：`<交接包>\scripts\pipeline\asset_library.db`（仅本机有效）
   - 自定义路径
   - 选中文件不存在 → 给复制指引（从工程 `assets\` 拷贝到所选位置，或联系制作人重跑 `scripts\make_nas_asset_db.py` 重新生成），不静默换选项
4. **轻量环境检测**（只报状态，不空跑施工，符合"环境自检挂账"纪律）：python 版本、sqlite3 可导入、ffmpeg 在 PATH、REAPER 常见安装目录、`~/.workbuddy/iris-config.json` 的 dashscope key 存在性（缺失不影响检索——自动降级为拆词纯 FTS 模式，仅提示召回质量下降）。逐项 ✅/⚠️ 报告。
5. **写机器配置** `~/.claude/foley_machine_config.json`（写前展示全文征询确认）：
   ```json
   {
     "library_mode": "nas 或 local",
     "nas_root": "\\\\192.168.9.251\\音效2\\资源库",
     "asset_db": "<步骤3所选绝对路径>",
     "path_prefix": "<nas 模式=nas_root；local 模式=D:\\音效文件>",
     "pipeline_dir": "<含 search_assets.py 的目录：优先交接包 pipeline，其次 NAS _索引，其次工程 scripts>",
     "env": {"python": "<版本>", "sqlite3": true, "ffmpeg": true, "reaper": true, "dashscope_key": true},
     "created_at": "<ISO8601 时间>"
   }
   ```
6. **收尾指引**：说明本配置是**机器级默认值**（每集施工时 skill 的 `foley_project.json` 才是权威，SOP 步骤① init 时引用此处默认值）；下一步等制作人提供视频路径与任务工作目录后用 `/分析` 开工。
